# CU-20 — Gestionar cambios de prendas

| Campo | Descripción |
| --- | --- |
| Caso de uso | CU-20 — Gestionar cambios de prendas |
| Descripción | Cambiar prendas de una venta entregada aplicando su crédito y la diferencia de efectivo. |
| Actor | Cajero / Encargado |
| Canal | Web |
| Precondiciones | El personal está autorizado; hay conexión; existe comprobante pagado y entregado; las unidades no fueron devueltas antes. |
| Postcondiciones | El cambio, nueva venta, crédito, efectivo, devoluciones y movimientos quedan registrados sin duplicación. |

## Flujo normal

1. Buscar el comprobante original.
2. Elegir unidades devueltas dentro del saldo disponible.
3. Elegir prendas nuevas y registrar el motivo.
4. Calcular crédito y diferencia con precios actuales.
5. Revisar efectivo recibido o devuelto.
6. Confirmar; guardar solicitud hasta conocer el resultado y mostrar el nuevo comprobante.

## Flujos alternativos

- Cambió stock o importe: no modificar inventario; calcular nuevamente.
- Se intenta devolver más de lo comprado: rechazar.
- Respuesta perdida o recarga: comprobar el mismo UUID antes de iniciar otro cambio.
- Comprobante de otra empresa o no pagado: no aceptar el cambio.
