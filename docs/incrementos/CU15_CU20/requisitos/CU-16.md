# CU-16 — Consultar operaciones pendientes y resultados de sincronización

| Campo | Descripción |
| --- | --- |
| Caso de uso | CU-16 — Consultar operaciones pendientes y resultados de sincronización |
| Descripción | Conocer qué se guardó, qué recibió la tienda y qué necesita revisión. |
| Actor | Cajero / Encargado / Cliente autorizado |
| Canal | Web PWA / Flutter |
| Precondiciones | El usuario inició sesión en la tienda correspondiente. |
| Postcondiciones | Se presentan operaciones del propietario con estado, fecha, intentos, detalles y resultado; no se mezclan cuentas ni empresas. |

## Flujo normal

1. Abrir Operaciones y resultados o las solicitudes del cliente.
2. Consultar el historial local sin conexión.
3. Filtrar estados y tipos disponibles en caja.
4. Con conexión, consultar resultados recientes del propietario.
5. Comprobar por UUID los pendientes que no aparecen en el historial reciente.
6. Abrir el comprobante confirmado o conocer el motivo de revisión.

## Flujos alternativos

- Sin conexión: conservar los últimos resultados y señalar los pendientes.
- Cambio de tienda o cuenta: ocultar el contexto anterior y mantener sus operaciones bajo su propietario.
- Acceso a una operación de otro propietario: no devolverla.
