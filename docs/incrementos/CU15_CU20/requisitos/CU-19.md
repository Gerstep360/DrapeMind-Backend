# CU-19 — Atender reservas y convertirlas en ventas presenciales

| Campo | Descripción |
| --- | --- |
| Caso de uso | CU-19 — Atender reservas y convertirlas en ventas presenciales |
| Descripción | Preparar la reserva, recibir el efectivo y registrar la entrega como una venta presencial. |
| Actor | Cajero / Encargado |
| Canal | Web PWA / Flutter |
| Precondiciones | Hay una reserva autorizada en la sucursal; el personal tiene acceso y una copia vigente si trabaja offline. |
| Postcondiciones | Una venta vincula comprador original, empleado, reserva, pago y sucursal; consume stock total y reservado una sola vez. |

## Flujo normal

1. Abrir Atender reservas.
2. Buscar número o código y revisar prendas y vigencia.
3. Con conexión, marcar la reserva lista.
4. Recibir el efectivo y confirmar el cobro y entrega.
5. Guardar el retiro con UUID, importes y todas las líneas de la reserva.
6. Sincronizar y consultar el comprobante de la empresa.

## Flujos alternativos

- Reserva vencida o cancelada: no convertir; revisar y devolver efectivo si ya fue cobrado.
- Ya tiene un cobro guardado: comprobar su resultado.
- Ya fue vendida con otra operación: registrar conflicto sin duplicar la venta.
- Las cantidades no coinciden con la reserva: impedir conversión parcial.
