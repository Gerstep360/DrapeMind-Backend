# CU-15 — Registrar ventas de contado sin conexión

| Campo | Descripción |
| --- | --- |
| Caso de uso | CU-15 — Registrar ventas de contado sin conexión |
| Descripción | Registrar prendas entregadas y efectivo recibido sin depender de una conexión. |
| Actor | Cajero |
| Canal | Web PWA / Flutter |
| Precondiciones | El cajero tiene sesión y descarga vigentes; está autorizado en la sucursal; dispone de catálogo y stock fechado. |
| Postcondiciones | La venta y su UUID quedan guardados antes de enviar; existe un comprobante provisional. Al sincronizar se registra una sola venta con pago y movimientos. |

## Flujo normal

1. Abrir Caja y reservas y seleccionar la sucursal.
2. Buscar y añadir tallas y cantidades.
3. Introducir el efectivo recibido; revisar total y cambio.
4. Confirmar el cobro y la entrega.
5. Guardar la operación en IndexedDB o SQLite.
6. Consultar o copiar el comprobante provisional y continuar atendiendo.

## Flujos alternativos

- El efectivo no cubre el total: no se guarda la venta.
- No hay descarga o sesión vigente: actualizar antes de iniciar otra operación; conservar pendientes.
- Cambió precio o stock al sincronizar: conservar el cobro en revisión y no crear registros parciales.
