# CU-18 — Gestionar operaciones rechazadas o en conflicto

| Campo | Descripción |
| --- | --- |
| Caso de uso | CU-18 — Gestionar operaciones rechazadas o en conflicto |
| Descripción | Resolver incidencias verificando stock, cobro y acuerdo con el cliente, con historial de decisiones. |
| Actor | Encargado / Administrador |
| Canal | Web |
| Precondiciones | El encargado tiene la sucursal asignada o el administrador pertenece a la empresa; existe un conflicto. |
| Postcondiciones | Se conserva la nueva validación o anulación, motivo, autor y fecha. No se fuerza inventario negativo. |

## Flujo normal

1. Abrir Operaciones por revisar.
2. Consultar el motivo, prendas, sucursal y persona que registró la operación.
3. Revisar precio guardado y precio actual del catálogo.
4. Registrar el motivo y corregir previamente el inventario real si corresponde.
5. Volver a validar, autorizando expresamente el precio cobrado cuando proceda, o anular.
6. Para anular una venta, confirmar la devolución del efectivo; conservar auditoría.

## Flujos alternativos

- Ya fue resuelta por otra persona: actualizar la lista sin repetir la acción.
- Continúa faltando stock: mantener el conflicto.
- No se confirma devolución del efectivo: impedir anulación de una venta.
- Sucursal cerrada: permitir revisar y anular con devolución, sin autorizar nuevas ventas.
