# Entregas académicas

[Incremento I — Capítulo IV: arquitectura e integración](Incremento_I_Capitulo_IV.zip).

El paquete contiene nueve diagramas, cada uno en PlantUML, SVG y PNG, con índice, estilo compartido y verificación de generación. Los títulos y nombres están fuera de las imágenes. Las piezas offline que aún no existen en el código se identifican como previstas.

La carpeta editable canónica se mantiene en `segundo parcial/Incremento I/capitulo-IV` del espacio de trabajo académico. El ZIP es una salida derivada y reproducible para conservar esta entrega en Main; no contiene variables privadas ni credenciales.

[Incremento I — Diez diagramas individuales de casos de uso](Incremento_I_Casos_de_Uso_Individuales.zip). Fuentes PlantUML, SVG y PNG de CU-01 a CU-10 del segundo parcial, con índice y verificación. La carpeta canónica es `segundo parcial/Incremento I/Capitulos-II/diagrama de CU`; los diagramas no renderizan títulos ni leyendas.
