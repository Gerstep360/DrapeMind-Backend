# Mini: generated responses, not canned answers

Removed the keyword intent router, its parallel tool execution path, and the
stylist response templates from `scout_orchestrator.py`. The deleted path also
referenced undefined `tool_name` and `arguments` variables.

- All natural-language requests enter the existing model-controlled tool loop.
- Mini synthesizes prose using Scout with compact state and observations, without
  the planning JSON schema or tool catalogue in that synthesis request.
- Mini never leases Gemma. Dynamic retains model-directed Gemma delegation.
- A generated `intro` may accompany verified product cards without another model
  call. It is model output, not a server-written answer.
- `observe` can continue searching in Mini; tools are not stopped after one read.
- Context updates, batched calls and picker fields remain available to the planner.
- Operational errors and UI labels remain deterministic; they are not presented
  as model-generated shopping advice. Inference failure has no canned fallback.
