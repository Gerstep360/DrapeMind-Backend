# Implementación del segundo parcial

| Entrega | Casos | Entrada |
| --- | --- | --- |
| [Incremento I](incremento_i/README.md) | CU-01 a CU-10 | incremento_i/router.py y servicios de dominio indicados en su índice |
| [Incremento II](incremento_ii/README.md) | CU-11 a CU-20 | incremento_ii/router.py |

Los incrementos agrupan las entregas funcionales; no son aplicaciones ni bases de datos separadas. Autenticación, aislamiento empresarial, planes e inventario tienen una sola implementación compartida.

Los nombres cuXX de app/modules conservan la numeración histórica del primer parcial. Para identificar los casos del segundo parcial se usa este índice, no se interpreta aquel número como la numeración nueva.
